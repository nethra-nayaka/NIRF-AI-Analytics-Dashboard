# NIRF AI Analytics Dashboard — Streamlit + Google Gemini

## 1. Requirements
- Python 3.10 or newer (Python 3.11 recommended)
- VS Code
- Google Gemini API key from Google AI Studio
- Your `FINAL_CLEANED.csv`

## 2. Folder setup
Keep the project structure:
```
NIRF_AI_Streamlit_Gemini/
  app.py
  data_utils.py
  nlq_engine.py
  requirements.txt
  .env
  data/
    FINAL_CLEANED.csv
```
Copy your existing `FINAL_CLEANED.csv` into the `data` folder.

## 3. Install
Open the VS Code terminal in this folder:
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```
If PowerShell blocks activation, run:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## 4. Configure Gemini
1. Open Google AI Studio: https://aistudio.google.com/app/apikey
2. Create an API key.
3. Copy `.env.example` to a new file named `.env`.
4. Put the key after `GEMINI_API_KEY=`.
5. Never share the key or upload `.env` to GitHub.

## 5. Run
```powershell
streamlit run app.py
```
Streamlit will print a local URL, usually http://localhost:8501.

## 6. Dataset column mapping
`data_utils.py` maps common variants into internal names:
- year
- category
- institution
- state
- city
- rank
- score
- institution_id
- zone
- tlr, rpc, go, oi, perception

If your CSV uses different names, add the source column name to the relevant `ALIASES` list in `data_utils.py`. The app shows the detected columns in the Data Quality page.

## 7. NLQ examples
- Which are the top 10 Engineering institutions in 2025?
- Compare average scores across categories in 2024.
- Show the score trend of IIT Madras from 2017 to 2025.
- Which states have the most institutions in the top 100?
- What is the average score in Karnataka?
- Show missing values and duplicate records.

## 8. Important notes
- Gemini creates a structured query plan; Pandas performs the calculations.
- The app does not execute arbitrary Python code generated by Gemini.
- Validate results against the CSV and your project requirements before presentation.
- Institution comparisons across years can be affected by name/ID changes. Use verified institution identity matching for longitudinal conclusions.
- API availability, model names, quotas and pricing can change. `GEMINI_MODEL` can be changed in `.env`.
